# Mini-projet Cinéma

Petit site réalisé avec HTML, CSS et JavaScript. Les films viennent de l’API OMDb.

## Configurer l’API

1. Le projet contient déjà le fichier `js/config.js` avec la clé OMDb.
2. Pour utiliser une autre clé, remplace la valeur de `API_KEY` dans ce fichier.
3. Ouvre le site avec Live Server dans VS Code.

Le site doit être lancé avec un serveur HTTP comme Live Server dans VS Code. Le fichier `js/config.js` contient la clé OMDb et sera envoyé sur GitHub avec le projet. Comme le dépôt est public, cette clé sera visible par tous.
